# SketchUp Dark Mode v1.0.0 🌓

Nowoczesne, dopracowane rozszerzenie Dark Mode dla **SketchUp 2025** na systemy Windows 10/11.  
*A modern, polished Dark Mode extension for **SketchUp 2025** on Windows 10/11.*

---

## 🇵🇱 Opis i Nowości (Polski)

Wydanie **v1.0.0** wprowadza pełną integrację ciemnego motywu w SketchUp 2025 opartego na silniku **Qt 6** oraz natywnym API Windows (DWM):

### 🌟 Główne Funkcje:
- **Pełny Ciemny Motyw Qt 6:** Elegancki ciemny wygląd menu, pasków narzędzi, domyślnego zasobnika, kart, okien dialogowych i paneli.
- **Natywny Pasek Tytułu Windows (DWM):** Ciemny pasek tytułu okna aplikacji zintegrowany z motywem Windows 10/11.
- **Ciemny Widok 3D (Viewport):** Ciemne tło obszaru roboczego z wyraźnymi, kontrastowymi krawędziami modeli.
- **Czytelne Etykiety Materiałów i Folderów:** Głęboko czarna, gruba czcionka (font-weight: 800) na białych kafelkach miniaturek i folderów w panelu Materiały – gwarantuje 100% czytelność bez zniekształcania podglądu tekstur.
- **Poprawione Menu Rozwijane:** Listy rozwijane wyboru kategorii materiałów w estetycznym ciemnym stylu bez białych obramowań.
- **Błyskawiczne Przełączanie Trybów:** Zoptymalizowane selektory CSS bez zawieszania programu przy zmianie motywu.
- **100% Natywny Tryb Jasny:** Po wyłączeniu ciemnego motywu interfejs powraca do czystego, fabrycznego stanu SketchUpa z zerowym narzutem.
- **Pełna Dwujęzyczność (PL / EN):** Automatyczne wykrywanie języka SketchUpa oraz opcja ręcznego wyboru w Ustawieniach.
- **Przeładowanie Stylu w Locie (Hot-Reload):** Możliwość odświeżenia arkusza stylów bez konieczności restartu programu.

### 📦 Instrukcja Instalacji:
1. Pobierz plik **`sketchup_dark_mode.rbz`** załączony poniżej w Assets.
2. Otwórz **SketchUp 2025**, przejdź do menu:  
   **Rozszerzenia** -> **Menedżer rozszerzeń** (*Extensions* -> *Extension Manager*).
3. Kliknij przycisk **Zainstaluj rozszerzenie** (*Install Extension*) i wskaż pobrany plik `sketchup_dark_mode.rbz`.
4. Wtyczka aktywuje się automatycznie i doda pasek narzędzi **Dark Mode**.

## 🇬🇧 Features & Highlights (English)

Version **v1.0.0** brings complete dark mode integration to SketchUp 2025 powered by **Qt 6** and Windows DWM:

### 🌟 Key Features:
- **Full Qt 6 Dark Theme:** Restyles menus, toolbars, docking trays, status bars, tab bars, dialogs, and panels.
- **Windows DWM Dark Titlebar:** Native dark window titlebar matching Windows 10/11.
- **Dark 3D Viewport:** High-contrast dark canvas background with crisp model edges.
- **Materials & Folders Readability:** Deep black, extra-bold text (font-weight: 800) elevated on folder swatches for crystal-clear readability.
- **Clean Dropdown Menus:** Category selector dropdowns with dark backgrounds and high-contrast text.
- **Instant Mode Switching:** Highly optimized stylesheet rules preventing UI freezes and lags.
- **100% Factory Standard Light Mode:** Disabling dark mode completely deactivates stylesheets and restores original Windows palettes.
- **Multilingual Support (PL / EN):** Automatic language detection with manual override in Settings.
- **Hot-Reload Support:** Instant CSS reloading without restarting SketchUp.

### 📦 Installation:
1. Download **`sketchup_dark_mode.rbz`** from the Assets below.
2. In SketchUp 2025, go to: **Extensions** -> **Extension Manager**.
3. Click **Install Extension** and select `sketchup_dark_mode.rbz`.
4. The extension will activate automatically and display the **Dark Mode** toolbar.
